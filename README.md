# Login / Register App

A simple Login / Register app built with React + TypeScript + Vite.

## Features

- 📝 Register Form (Name, Email, Password)
- 🔐 Login Form
- 👋 Welcome Message after Login
- 🚪 Logout
- 💾 Data Persistence (localStorage)
- ✅ Form Validation
- 🗑️ Clear All Users

## Tech Stack

- **React** - UI Library
- **TypeScript** - Type Safety
- **Vite** - Build Tool
- **localStorage** - Data Persistence

## Installation

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
